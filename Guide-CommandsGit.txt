Comandos:

git init {inicia localmente una instancia de git}

git add . {añade todos los archivos al repositorio}

REPOSITORIO NUEVO ------> Enlace y Subir

git commit -m "first commit" {Sirve para nombrar la versión de subida}

git push {subir los cambios}

git pull {baja los cambios}

git status {comprueba si hay cambios o el estado de los archivos}
